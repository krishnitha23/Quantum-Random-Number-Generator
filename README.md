# Quantum Random Number Generator

## About
My first quantum computing project using Qiskit.

## Concepts Learned
- Quantum circuits
- Hadamard gates
- Quantum superposition
- Quantum measurement
- Measurement statistics

## Tools Used
- Python
- Qiskit
- Qiskit Aer
- Google Colab

## Experiment
I created a one-qubit circuit using a Hadamard gate
and measured it repeatedly to study the outcomes 0 and 1.

## Learning Outcome
I explored how quantum measurement produces probabilistic
outcomes and how observed frequencies vary with the
number of measurements.

## Note
The experiments use a quantum simulator, not a
physical quantum computer.
